**[LangBot](https://github.com/langbot-app/LangBot)** is an open-source platform that connects Large Language Models to instant messaging platforms. Build, debug, and ship AI-powered bots to **Discord, Telegram, Slack, LINE, WeChat, QQ, Lark, DingTalk** and more — from a single codebase.

### Highlights

- **Universal IM support** — One bot for 10+ platforms including Discord, Telegram, Slack, LINE, QQ, WeChat, WeCom, Lark, DingTalk, KOOK.
- **Any LLM, any provider** — OpenAI, Anthropic, DeepSeek, Gemini, Ollama, and many more. Integrates with Dify, Coze, n8n, Langflow, and MCP protocol.
- **Production-ready** — Access control, rate limiting, sensitive word filtering, monitoring, and multi-pipeline architecture. Trusted by enterprises.
- **Plugin ecosystem** — Hundreds of community plugins with an event-driven architecture. Browse them on [LangBot Space](https://space.langbot.app).
- **Web management panel** — Configure and monitor everything from your browser.

### Get Started

```bash
uvx langbot
```

Visit `http://localhost:5300` and you're ready to go. See the [documentation](https://langbot.app/docs/en/insight/guide.html) for Docker, cloud deploy, and other options.
